# Changelog

## 1.0.2

- Replaces a Halls reward only when equipment filtering would leave that roll empty.
- Added tier-appropriate material replacements and optional Path of Valheiman currency replacements.
- Added replacement configuration options.

## 1.0.1

- Added the automatically generated `Dorn.PoVHallsChests.cfg` server configuration file.
- Added `Enabled`, `Filter scope`, and `Log removed items` options.

## 1.0.0

- First public release.
- Removes equipment rewards generated by the Path of Valheiman Halls of Oaths route.
- Preserves currencies, runes, gems, and materials from Halls rewards.
- Covers Halls chest, trial, breakable, and encounter/boss reward rolls.
- Server-side only; clients do not need the mod.
